🔎 디지털 데이터 탐험 연구소

문자, 이미지, 소리, 동영상을 직접 조작하고 컴퓨터가 데이터를 표현하는 방법을 관찰해 보세요.

미션 1. 나만의 비밀 메시지 만들기

원하는 영문 단어를 입력하면 각 글자가 0과 1로 바뀌어요. 만들어진 코드를 다시 해독해 보세요.

① 문자 → 이진수

영문 대문자 A~Z만 사용해요. 각 문자를 8자리로 표시합니다.

② 이진수 → 문자

해독 결과

아직 해독하지 않았어요.
문자마다 정해진 코드가 있어요. 여기서는 영문 대문자의 ASCII 코드를 8자리 이진수로 표시합니다. 8비트 계산은 하지 않아도 돼요.

미션 2. 픽셀로 그림 만들기

칸을 눌러 그림을 그려 보세요. 검은색은 1, 흰색은 0으로 바뀝니다.

① 픽셀 그림

② 0과 1로 표현한 결과

검은색 = 1   흰색 = 0

왼쪽에서 오른쪽, 위에서 아래 순서로 읽어요.

격자 크기가 커지면 표현할 수 있는 세부 모양이 늘어날 수 있어요. 하지만 실제 사진의 선명도는 해상도뿐 아니라 여러 요인에도 영향을 받아요.

미션 3. 소리가 숫자로 바뀌는 과정

고정된 파형에서 일정한 시간 간격으로 측정한 표본을 선택하고, 그 값이 0과 1로 바뀌는 과정을 관찰하세요.

① 파형에서 표본 선택하기

파란 선은 연속적인 소리 파형의 예시이고, 점은 같은 시간 간격으로 측정한 표본이에요. 점 또는 아래 버튼을 눌러 표본을 선택해 보세요.

선택한 표본: 1번

② 표본화 → 양자화 → 부호화

표본값
-
양자화
-
3비트 부호화
-

표본화 : 일정한 시간 간격으로 파형의 값을 측정해요.

양자화 : 측정값을 정해진 단계로 나타내요.

부호화 : 양자화한 값을 0과 1로 표현해요.

학습용 단순화 모형: 파형의 높이를 0~7 범위의 값으로 나타내고, 가장 가까운 정수로 양자화한 다음 3비트 이진수로 표현합니다. 실제 소리의 디지털 변환에는 더 다양한 표본화 주파수와 양자화 방식이 사용됩니다.

미션 4. 움직임을 만드는 프레임

같은 1초 동안 공이 왼쪽에서 오른쪽으로 이동하는 모습을 2FPS와 8FPS로 비교해 보세요.

① 움직임 비교

2 FPS · 1초 동안 2장의 프레임

② 1초 동안의 프레임

FPS는 1초 동안 표시되는 프레임 수예요.

같은 1초의 움직임이라도 프레임 수가 많으면 중간 모습이 더 많이 표현되어 움직임이 더 부드럽게 보일 수 있어요.

선택한 프레임 수

2장
동일한 이동 거리와 재생 시간(1초)을 사용합니다. 재생 중 화면은 각 FPS에 맞춰 위치가 단계적으로 바뀌어요.

활동 방법: 연구실을 하나씩 체험한 뒤 관찰한 결과를 활동지에 기록하세요. 인터넷 연결 없이 이 파일만 열어도 작동합니다.
